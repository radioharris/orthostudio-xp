# OrthoStudio XP 0.1.3 (beta)

The Copernicus relief, hand-made mesh patches, and decals on land only — what the users of the
X-Plane.Org page asked for after 0.1.2.

## What changed

- **A finer relief, if you want one.** Settings now offers the **Copernicus relief** (GLO-30, one
  arc-second) beside X-Plane 12's own and your own elevation file. It is downloaded once (about
  40 MB per one-degree square) and kept, so a tile built again costs nothing more; on a test tile
  the build took about 30 s longer the first time. X-Plane 12's own relief stays the default: it
  matches the scenery around your tile and downloads nothing.
- **Which relief a build used.** Works says it on each tile, as the build runs, so a tile built
  from Copernicus is no longer indistinguishable from one built from X-Plane's relief.
- **Hand-made mesh patches.** Under *For experts*, *Folder of hand-made mesh patches* takes a
  folder of `*.patch.osm` files written with JOSM — one directory per tile — and the tiles that
  have one are built with it. The patches their authors publish for Ortho4XP fit **as they are**,
  in the tree they come in (`Patches/-20-050/-20-044/SBCF.patch.osm`): name the folder you
  unzipped, its `Patches`, or the tile's own directory, whichever you kept. *Choose…* opens your
  system's folder dialog, and left empty the field uses OrthoStudio XP's own `patches` folder
  (`~/.orthostudio/patches` on macOS and Linux, `%USERPROFILE%\.orthostudio\patches` on Windows),
  which the app now creates for you. Editing a patch builds that tile again by itself, and the
  build says what it used — or that a file none of whose ways could be read changed nothing.
- **Decals on land only.** The fine ground grain at very low height (`use_decal_on_terrain`) no
  longer goes on the sea, where a user found it out of place on water. It stays off by default;
  *Fine ground detail on the sea too* puts it back everywhere, as Ortho4XP writes it. Lakes and
  rivers never had it.
- **`osxp build --relief copernicus`** on the command line, the same three reliefs as the page.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit*, at the top right of its page), then replace the app; on Windows, the installer stops
a running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.3-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.3-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.3-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.3-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app;
the README says how to open it anyway. The known limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.local/state/OrthoStudio XP/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
