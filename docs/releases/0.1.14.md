# OrthoStudio XP 0.1.14 (beta)

The faults users wrote in about are gone, a world source joins the list, and Ortho4XP tiles
import from wherever you keep them.

## What changed

- **Shift and a rectangle choose squares**, or sweep them with the mouse; drawn from a chosen
  square it takes them out instead.
- **A build takes up to 500 tiles**, not 64, and the Plan says so in plain words.
- **Choose an airport by its code and the map goes there**, so the squares it chose are in
  front of you.
- **A zone can be drawn on the imagery grid**: hold the keys and the grid appears, the shape
  follows it, and the page says how far each point moved.
- **A click on the map lands under the pointer**, whatever the window has done since it opened,
  and the first point of a shape is no longer eaten by the sweep.
- **EOX's Sentinel-2 as a world source**, ZL14 at most, light on a machine and made for flying
  high. Its licence is non-commercial.
- **Ortho4XP tiles import from any folder holding them**, not only from an Ortho4XP installation.
- **A zone's colours are painted on the ground it covers**, whatever its size: a zone smaller
  than a texture changed nothing at all before. A tile you already built with a zone is built
  again the first time, to get the colours it should have had.
- **A step that takes minutes says what it is doing**, so a build that looks stopped can be told
  from one that is.
- **A build no longer sits forever on a texture whose encoder never answers**, and no longer
  announces a million hours remaining.
- **A build you stopped no longer reads 99 %**: the bar says how much was built, and the status
  says whether it is over.
- **A folder of relief files of your own may miss a square**, as Settings says it may: the relief
  you chose is used there, instead of the tile failing with nothing built.
- **A relief file you correct is used**: it was remembered by its path, so mending the file
  changed nothing.
- **A texture nothing came back for is not shipped as grey ground.**
- **A texture holds the memory the build set aside for it**, and a zone's soft edge no longer
  shows the very join it exists to hide.
- **A source that blocks you for a moment is asked again**, instead of failing the tile at once,
  and a tile that fails on its imagery says what the server answered.
- **A source may be told how many requests a second it will take** (`server_req_per_s` in your
  `sources.toml`), and a server that closes the door is knocked on more gently.
- **A map data server that has had enough of your address says so**, with what to do about it,
  and the card offers *Try again*.
- **Checks asks the map data servers whether it is them or you**, so a build that cannot get its
  roads and water has an answer without guessing.
- **`serve.log` holds every stage of a build**, so a build that stops has something to send;
  on Linux it now sits in `~/.orthostudio/log`, beside everything else of ours, instead of
  the folder nobody finds. Past eight megabytes it is set aside as `serve.log.1`.
- **Two ways of losing scenery are closed**: taking a tile out no longer removes another pack's
  line from `scenery_packs.ini`, and no tile is deleted whose only folder is the one inside
  X-Plane.
- **A tile goes above AutoOrtho and above a base mesh**, both, so it is not drawn under one of
  them while the Library says it is installed.
- **A tile built without installing is in the Library**, with its size and where it is.
- **A deletion interrupted no longer leaves a half-emptied tile** that the next build adopts and
  calls done.
- **A full disk, a read-only drive and a folder without permission are said as themselves**, not
  as internal errors to be reported, and no remedy names a command this program does not have.
- **Checks fails when Triangle4XP is missing**, instead of saying everything is fine while no
  tile can be built at all.
- **Each built tile carries a `CREDITS.txt`**: who the imagery belongs to and what it is given
  under, so a pack you pass on carries its credit. EOX's is non-commercial, and the Plan says so
  beside the source.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the page, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.14-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.14-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.14-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.14-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app,
and a browser may refuse to download them; the README says how to open them anyway. The known
limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.orthostudio/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
