# OrthoStudio XP 0.1.12 (beta)

A repair, and nothing else: builds were failing on the Data step everywhere, because two of the
three public OpenStreetMap servers OrthoStudio XP asks for its map data are gone.

## What changed

- **OrthoStudio XP asks the map data servers that answer.** `lz4.overpass-api.de` had stopped
  answering and `overpass.openstreetmap.fr` now refuses everyone ("only available to white-listed
  usages"), which left builds with nowhere to get the roads, water, coastline and airports of a
  tile. It now asks `overpass-api.de` first, then the four others in turn, the French one last of
  all in case it opens again.
- **When a tile does fail for want of map data, the page says which server said what**, instead
  of "could not be obtained from any mirror".
- **Pressing *Build* again gives every server a fresh chance.** A server put aside was refused
  for up to an hour, so every later build failed in four seconds and quitting the app was the
  only way out.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the page, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.12-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.12-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.12-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.12-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app,
and a browser may refuse to download them; the README says how to open them anyway. The known
limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.local/state/OrthoStudio XP/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
