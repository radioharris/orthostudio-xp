# OrthoStudio XP 2.0.1

## What changed

- Live now uses the X-Plane folder chosen in Settings, as Build does. On a computer with two X-Planes, it could take the other one and not start yours.
- Live's Settings now ask where X-Plane 12 is installed. It is one setting with Build's, so your tiles and Live always go to the same X-Plane.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the window, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself, Live included, and asks first if X-Plane is flying with Live.

| System | File |
|---|---|
| macOS 15 or later, Apple Silicon | `OrthoStudio-XP-2.0.1-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-2.0.1-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-2.0.1-windows-x64-setup.exe` |
| Linux, 64-bit | `OrthoStudio-XP-2.0.1-linux-x86_64.tar.gz` |

The installers are **not signed**, so macOS and Windows warn the first time you open the app, and
a browser may refuse to download them; the README says how to open them anyway.

## Known limitations

Those of [1.0](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/1.0.0.md#known-limitations) and [1.4](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/1.4.0.md#known-limitations) still apply. Live's own:

- **Linux.** Live has flown with X-Plane 12 on Macs and on a Windows PC, not yet on Linux.
- **The mesh.** Live lays its photos on it, region by region (4 to 42 GB each, installed from its
  Settings): where no region is installed, X-Plane shows its own scenery, without photos.
- **One ortho program at a time.** Quit XPME or AutoOrtho before you start Live.
- **The window over a paused X-Plane** is not there on Linux: X-Plane waits, without Live's progress.
- **The disk.** Live writes more to the disk than XPME on the same flight: each texture is written
  whole as it gets sharper.

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)) and choose
*A problem*. Its form asks for the version, your system, what you did and what you saw, the tile
(`+46+006`), a screenshot, and the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.orthostudio/log` on Linux). For Live, add
`LogLive.txt`, at the top of your X-Plane folder beside X-Plane's own `Log.txt`, and that `Log.txt`.
An idea goes to the [Ideas](https://github.com/radioharris/orthostudio-xp/discussions/categories/ideas)
of the Discussions, where others can vote for it, and a question to
[Q&A](https://github.com/radioharris/orthostudio-xp/discussions/categories/q-a).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
