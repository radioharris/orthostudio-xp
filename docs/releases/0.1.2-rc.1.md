# OrthoStudio XP 0.1.2rc1 (release candidate)

A release candidate for **Intel Macs**: the first installer of OrthoStudio XP for a Mac with an
Intel processor. It is built and checked automatically, under Rosetta on an Apple Silicon Mac, but
nobody has run it on an Intel Mac yet: if you have one, please try it and tell us how it goes.

0.1.1 stays the current version for everyone else. Apart from their version number, the other
installers of this candidate are the same as 0.1.1's.

## Install

| System | File |
|---|---|
| Intel Mac, macOS 15 or later | `OrthoStudio-XP-0.1.2rc1-macos-x86_64.dmg` |
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.2rc1-macos-arm64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.2rc1-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.2rc1-linux-x86_64.tar.gz` |

On a Mac, open the `.dmg` and drag *OrthoStudio XP* to Applications. The app is not signed yet, so
macOS refuses to open it the first time: *Getting started* in the README says how to open it
anyway. The Intel app needs macOS 15, since one of its libraries (pyproj, for the map projections)
is built for macOS 15 on Intel.

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, and the log `serve.log`
(`~/Library/Logs/OrthoStudio XP` on macOS). Without a GitHub account, the comments on OrthoStudio
XP's page on X-Plane.Org are read too.
