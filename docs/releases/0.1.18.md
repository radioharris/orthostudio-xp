# OrthoStudio XP 0.1.18 (beta)

Choose the tiles along your SimBrief flight plan, choose the ground's decal, and see on the map
which tiles OrthoStudio XP and Ortho4XP built.

## What changed

- Flight plan: *My SimBrief plan* reads your last SimBrief plan and chooses the tiles at both ends and along the route, each group at its own detail level.
- Decals: choose which of X-Plane 12's decals the ground takes (Settings, For experts); turning them on or off, or choosing another, rewrites a built tile in about a second, with nothing downloaded.
- The map colours a tile by who built it, green for OrthoStudio XP and violet for Ortho4XP, solid when X-Plane has it and dashed when not; the legend gives each kind a line and a box, and its options fold away.
- Works shows OSM, Relief and Terrain as steps of their own, and says when a tile's map data has arrived.
- Search a tile in Works and in the Library, and sort the Library by any column.
- Going back to colours already built puts their photos back in X-Plane.
- The Library tells a tile's colours right even when its cache no longer has them.
- Map data from the library comes faster, above all far from Europe.
- Opening OrthoStudio XP after an update no longer leaves the old engine running.
- The data folder is no longer forgotten when the settings file cannot be read for a moment.
- The log no longer names the map data server when a download fails.
- Every source file now says where its licence and the NOTICE's additional terms are.
- Building again a tile built with decals by 0.1.17, or with *on the sea too* ticked, redoes it once; one built with other colours than the plain ones only has its pack assembled again, in seconds.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the page, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.18-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.18-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.18-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.18-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app,
and a browser may refuse to download them; the README says how to open them anyway. The known
limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.orthostudio/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
