# OrthoStudio XP 0.1.2 (beta)

An installer for Intel Macs, and what the first users of the X-Plane.Org page ran into.

## What changed

- **An installer for Intel Macs**, macOS 15 or later: `OrthoStudio-XP-0.1.2-macos-x86_64.dmg`. It
  is built and checked automatically, and it has been run under Rosetta on an Apple Silicon Mac;
  nobody has run it on an Intel Mac yet, so tell us how it goes. (It needs macOS 15 because one of
  its libraries, pyproj, is built for macOS 15 on Intel.)
- **Which X-Plane 12 a tile went into.** A user's tile went into an X-Plane 12 he had forgotten,
  and he found nothing in the Custom Scenery of the one he flies. With more than one X-Plane 12 on
  the computer, Settings now names the others under the detected one, and the Library says which
  X-Plane its *In X-Plane* column speaks of.
- **The data folder.** The question now says the folder must be outside X-Plane's Custom Scenery,
  where OrthoStudio XP puts its own links: a user typed his Custom Scenery there and was only
  refused once he had saved.
- **After a build without install**, the report says the tiles are not in X-Plane yet, with a
  button that opens the Library. And when a folder is not an Ortho4XP one, the import's refusal
  now says that a tile OrthoStudio XP built needs no import: the Library adds it to X-Plane.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit*, at the top right of its page), then replace the app; on Windows, the installer stops
a running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.2-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.2-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.2-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.2-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app;
the README says how to open it anyway. The known limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.local/state/OrthoStudio XP/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
