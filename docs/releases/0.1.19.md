# OrthoStudio XP 0.1.19 (beta)

Detail zones that cover everything you draw, reliefs that download on any line, and builds that
stay fast and safe on a hard disk.

## What changed

- A detail zone now sharpens every square of about 1 km it covers a part of: a small zone, such as a helipad, is no longer ignored.
- A relief file downloads as it arrives, beside the images, with no 30 s cut, and Cancel stops it.
- Works shows the relief's speed as it downloads, then that it is being read.
- Builds on a hard disk write faster, and wait for a busy index instead of failing.
- A file held by another program (an antivirus, a sync tool) no longer fails the tile; the next build checks it.
- After a power cut or a crash, the next build checks what was not yet safe on the disk; a normal *Build again* starts at once.
- The Library and the status bar show at once, even on a hard disk.
- *Build again* builds in the data folder and the X-Plane folder chosen now, and keeps the hand-made patches after a restart.
- The data folder's refusals name shared folders, a drive letter alone and a folder not made yet, and never advise formatting.
- Works names the USGS relief at 1", and the lidar or ANADEM under a folder of one's own.
- A tile whose coastline the map library would refuse takes the public servers instead.
- The help of the overlay exclusions names both kinds of autogen, `.ags` and `.agb`.
- Building again a tile with zones redoes it once; other tiles only rebuild their DSF, in about a second.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the page, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.19-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.19-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.19-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.19-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app,
and a browser may refuse to download them; the README says how to open them anyway. The known
limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.orthostudio/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
