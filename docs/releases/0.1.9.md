# OrthoStudio XP 0.1.9 (beta)

The window catches up with the browser it replaced: search, Find, and the zoom keys. And a
build no longer starts with a source you did not choose.

## What changed

- **Saving Settings no longer changes your Plan.** Choosing Bing for a tile, then saving an
  unrelated setting, put the settings' own source back and built with that one instead, without
  saying so. The detail level went the same way. They now follow only what the save changed.
- **Search the settings.** A field at the top of Settings narrows the two columns and the 40
  expert settings to what you type, by label, by help text or by Ortho4XP name: `min_area` finds
  *Smallest pond drawn as water*.
- **Cmd+F / Ctrl+F finds text on the page**, on any screen, as a browser does. The window had
  none.
- **Cmd+ / Cmd- / Cmd+0 change the text size**, and the size is remembered. The window had none
  of these either, which is why the text looked bigger than in your browser with no way back.
- **A build that failed or was stopped offers *Build again*** in its own header. It was hidden
  inside an error card, and only for some errors.
- **The USGS relief at 1 arc-second**, which reaches the United States, Canada, Mexico and
  Alaska. Over Canada those heights come from old map contours rather than measurement, so they
  can step in terraces; the note says so.
- **Works says which relief was really used.** A composite relief (Canada's lidar, ANADEM) falls
  back to what it is laid over where it has nothing, and the line named your choice back at you:
  a Banff build with lidar chosen was Copernicus throughout.
- **The report says which tiles were built with your patches**, and names the files.
- **Windows: the window carries the app's icon**, not Python's, and the three tools at the top
  right line up.
- **The import says what it does.** *Import my Ortho4XP tiles* reads and lists; nothing is
  copied, moved or deleted, and your tiles stay where Ortho4XP put them. The page now says so.
- **The page that says the engine stopped no longer offers to close a tab** that is a window.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the page, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.9-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.9-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.9-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.9-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app,
and a browser may refuse to download them; the README says how to open them anyway. The known
limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.local/state/OrthoStudio XP/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
