# OrthoStudio XP 0.1.10 (beta)

Each tile now remembers how it was built, and the Plan says what a new build would change on a
tile you already have. On Windows, fixes for a page that showed only the menu.

## What changed

- **Each tile remembers how it was built**: source, detail level, relief, colours, zones and
  patches, shown in the Library and in the Plan.
- **The Plan says what a build would change on a tile you already have** (another source,
  detail level or colours), and marks the tile's chip.
- **Import Ortho4XP tiles with one button**, and take one off the list with *Remove from the
  list*.
- **The Plan and Settings name the patches found for each tile**, before anything is built.
- **The page says when a newer version is out.**
- **Windows: fixes for a page that showed only the menu**, and the page no longer waits for the
  engine's slower answers before showing a screen.
- **On the map, a tile both installed and chosen shows both outlines**, and stays green when
  zoomed out on the world.
- Some tweaks.

## Install

Download the installer of your system below, then follow *Getting started* in the README.
Installed over an older version, it keeps your tiles and settings: on macOS, quit OrthoStudio XP
first (*Quit* in the page, or Cmd+Q), then replace the app; on Windows, the installer stops a
running OrthoStudio XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.10-macos-arm64.dmg` |
| macOS 15 or later, Intel | `OrthoStudio-XP-0.1.10-macos-x86_64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.10-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.10-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app,
and a browser may refuse to download them; the README says how to open them anyway. The known
limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.local/state/OrthoStudio XP/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
