# OrthoStudio XP 0.1.1 (beta)

Fixes for what the first users reported on X-Plane.Org after 0.1.0.

## What changed

- **Opening the app again works on Windows.** Closing the page leaves OrthoStudio XP running, so
  that a build goes on, and opening the app again shows its page. On Windows, that second launch
  gave up too early and showed nothing until OrthoStudio XP was ended in the Task Manager. It now
  recognises the running OrthoStudio XP at once.
- **OrthoStudio XP stops by itself** five minutes after its last page is closed, unless a build is
  running or waiting: nothing else showed that it still ran. *Quit*, at the top right of the page,
  still stops it at once.
- **Decals are easier to find**: *Settings*, *For experts*, "Fine ground detail at very low height
  (decals)". X-Plane 12 ships the decal it uses, and the setting's help no longer says it might not.

## Install

Download the installer of your system below, then follow *Getting started* in the README. Installed
over 0.1.0, it keeps your tiles and settings: on macOS, quit OrthoStudio XP first (*Quit*, at the
top right of its page), then replace the app; on Windows, the installer stops a running OrthoStudio
XP by itself.

| System | File |
|---|---|
| macOS 14 or later, Apple Silicon | `OrthoStudio-XP-0.1.1-macos-arm64.dmg` |
| Windows 10 or 11, 64-bit | `OrthoStudio-XP-0.1.1-windows-x64-setup.exe` |
| Linux, 64-bit (experimental) | `OrthoStudio-XP-0.1.1-linux-x86_64.tar.gz` |

The installers are **not signed** yet, so macOS and Windows warn the first time you open the app;
the README says how to open it anyway. The known limitations of 0.1.0 still apply:
[docs/releases/0.1.0.md](https://github.com/radioharris/orthostudio-xp/blob/main/docs/releases/0.1.0.md).

## Reporting a problem

Open an issue in this repository
([New issue](https://github.com/radioharris/orthostudio-xp/issues/new/choose)). Its form asks for
the version, your system, what you did and what you saw, the tile (`+46+006`), a screenshot, and
the log `serve.log` (`~/Library/Logs/OrthoStudio XP` on macOS,
`%LOCALAPPDATA%\OrthoStudio XP\Logs` on Windows, `~/.local/state/OrthoStudio XP/log` on Linux).
Without a GitHub account, the comments on OrthoStudio XP's page on X-Plane.Org are read too.
