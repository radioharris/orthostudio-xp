# native

`triangle4xp/`: Triangle 1.6 (J. R. Shewchuk) as modified by Oscar Pilote for Ortho4XP, plus
the OrthoStudio XP binary I/O modifications. Built with CMake. See `CHANGES.md` for the list of
modifications required by Triangle's licence.

`dsftool/`: DSFTool 2.3.0-b2 by Laminar Research (X-Plane Scenery Tools, MIT/X11), the macOS,
Windows and Linux binaries, used to extract the overlays. See `dsftool/README.md`.
